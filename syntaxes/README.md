# ISPA syntax highlighting

`ispa.tmLanguage.json` is a standalone TextMate grammar for ISPA grammar source files (`.isc`). It highlights rule declarations, nested rules, directives, string literals, character classes, numeric literals, operators, comments, and CLL expressions introduced by `$` and terminated by `;`.

The file uses the TextMate grammar format, which is supported by many editors and is also suitable for GitHub Linguist when added to a Linguist-supported editor integration. GitHub's repository code view does not provide a way for a repository to load a custom grammar directly; the grammar is provided for consumers to install or integrate.
